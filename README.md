# «Цифровой цех» — личный сайт-портфолио

Одностраничный статичный сайт: без сборщиков, зависимостей и конструкторов. Папка полностью самодостаточна — её можно вынести в отдельный репозиторий и залить на любой статичный хостинг как есть.

## Структура

```
personal_site/
├── index.html        — вся разметка и тексты (секция #products — магазин: набор из 10 шаблонов + бандл)
├── css/style.css     — стили (палитра и шрифты — в :root)
├── css/products.css  — стили продуктовой полки
├── js/main.js        — появление секций при скролле, год в футере
├── robots.txt        — разрешает всё + строка Sitemap
├── sitemap.xml       — 6 URL (домен-заглушка — заменить после деплоя)
├── .nojekyll         — для GitHub Pages
├── assets/img/       — рендеры работ + превью продуктов (prod_*.png)
├── assets/logo/      — логотип (копии из cifrovoj_ceh\logo)
└── README.md
```

## Как посмотреть локально

Открыть `index.html` двойным кликом. Интернет нужен только для шрифтов Google Fonts (Manrope, Cormorant Garamond); без сети сработает системный фолбэк — вёрстка не поедет.

## Как задеплоить

- **GitHub Pages:** выложить папку в репозиторий → Settings → Pages → ветка `main`, папка `/root`.
- **Netlify / Vercel:** drag-and-drop папки в дашборд.
- **Любой хостинг:** скопировать содержимое в корень сайта.

Примечание: для соцсетей `og:image` лучше указать абсолютным URL после деплоя (относительный путь scrape-боты не подхватят).

## Что править перед публикацией

1. **Ссылка Kwork** — в `index.html` стоит заглушка (найти по `TODO`), заменить на реальный профиль.
2. **Цены и сроки** — секция `#services`; карточки продуктов — `#products`.
3. **Работы** — карточки в `#works`: картинка из `assets/img/` + подпись.
4. **Цвета и шрифты** — переменные `:root` в `css/style.css`; полка продуктов — `css/products.css`.
5. **Домен** — после деплоя заменить в `sitemap.xml` и сделать `og:image` абсолютным.

## Источники ассетов

Картинки и логотип скопированы из `cifrovoj_ceh\brand_portfolio\` и `cifrovoj_ceh\logo\`. Править **копии здесь** — исходники в «Цехе» остаются нетронутыми и используются для постов канала.
